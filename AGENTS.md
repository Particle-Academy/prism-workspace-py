# AGENTS.md — prism-ai-workspace

Read `repos/prism-parity/docs/AGENTS.md` and the PHP reference package's
`AGENTS.md` before changing this package.

The guard is the product. Changes to path admission or filesystem containment
are security changes. Stable refusal codes and check order are cross-language
contracts. Run tests, Ruff, mypy, shared conformance, and security review.

Network and durable APIs are async-first with a sync facade. This package never
executes workspace contents.
